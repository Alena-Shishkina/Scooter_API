# Sprint 7 — Тестирование API сервиса «Яндекс.Самокат»

### Описание проекта

Этот проект содержит автоматизированные тесты для учебного API сервиса Яндекс.Самокат.
API доступно по документации: qa-scooter.praktikum-services.ru/docs/.

### Тесты написаны на Java + Maven с использованием:

- JUnit 4
- RestAssured
- Allure (для генерации отчётов)
- DataFaker (для генерации тестовых данных)

Перед автоматизацией API было протестировано вручную в Postman.

### Что сделано в проекте:

OrderStep

## Покрытие тестами
### 1. Создание курьера

Проверено:

✔ можно создать нового курьера

✔ нельзя создать двух одинаковых курьеров

✔ для создания обязательны все поля

✔ корректный статус-код при успешном создании

✔ успешный запрос возвращает {"ok": true}

✔ если одного из обязательных полей нет → возвращается ошибка

✔ если логин уже занят → возвращается ошибка

Также в After методы вынесено удаление созданных курьеров.

### 2. Логин курьера

Проверено:

✔ курьер может авторизоваться

✔ обязательные поля обязательны

✔ ошибка при неправильном логине или пароле

✔ ошибка, если логинится несуществующий пользователь

✔ успешная авторизация возвращает id

### 3. Создание заказа (с параметризацией)

Проверено:

✔ можно указать только BLACK

✔ можно указать только GREY

✔ можно указать оба цвета

✔ можно не указывать цвет

✔ тело ответа содержит поле track

Для тестов используется @RunWith(Parameterized.class) + конструктор с обработкой цвета.

### 4. Список заказов

Проверено:

✔ эндпоинт возвращает список заказов

✔ тело ответа содержит массив заказов

## Независимость тестов

Все тесты изолированы.

Курьеры создаются перед тестом и удаляются после теста.

Данные заказа не мешают последующим запускам.

## Используемые технологии

- Java 11	основной язык

- JUnit 4	фреймворк тестирования

- RestAssured	отправка HTTP-запросов

- Allure	генерация отчётов

- DataFaker	генерация тестовых данных

### Как запустить тесты
mvn clean test

### Генерация отчёта Allure

1. Сначала выполнить тесты:

mvn clean test


2. Затем сгенерировать отчет:

allure serve target/allure-results
